# 비트코인 사이클 저점 연구 — PC 프로젝트용 지식 요약 (2026-11-20)

이 파일은 Claude Code 세션(저장소 SANGMOLEE/soxl-data, 브랜치 ccr-b178db42-c7x4uo)에서 한 연구를 PC 프로젝트가 이어받기 위한 요약이다. 원본은 저장소 `research/`에 있고, 결론이 바뀌면 저장소 문서를 먼저 고친 뒤 이 파일을 다시 올린다.

## 역할과 규칙
- 목표: 사이클 최저점을 **탐지해서** 매수한다. 저점이 지난 뒤 확인하고 사는 것은 늦다. 최저점 당일은 못 잡으므로 서로 다른 속도의 지표 세 층과 알람을 겹쳐 최저점 ±10% 안에 3분할로 들어간다.
- 추정치보다 실측 자료(Yahoo 일봉, Coin Metrics 온체인)를 쓴다. 종목 추천은 하지 않는다(나스닥 기준 판정만).
- 설정·확률은 결과를 보기 전에 `forward_log.md`에 사전 등록하고, 결과를 본 뒤 바꾼 것은 "사후"라 적는다.
- 확인된 것과 확인되지 않은 것을 나눠 말한다.
