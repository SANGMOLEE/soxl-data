## 0. 결론 요약

1. **반도체급 사이클 산업은 7개(A등급)** — 반도체·주택건설·석유가스 E&P·금광주(귀금속)·바이오텍·지역은행·우라늄. B등급(사이클은 있으나 레버리지 이력이 짧거나 정책 변수가 큼) 5개 — 구리·리튬·태양광·장기국채·브라질. 천연가스는 선물 롤비용 감쇠라 제외.
2. **저점 동시성은 실재하나 돈은 SOXL이 가장 많이 번다.** 2016·2018·2020·2025 네 번은 전 자산이 같은 달 바닥. SOX 저점 월말 매수 12개월 배수 중앙값 SOXL 3.44배 > GUSH 2.39 > LABU 2.15 > TNA 2.00 > NAIL 1.95. 5종 바구니는 2.69배로 더 낮고 최악(0.94배)도 나쁘다. NAIL만 SOXL의 최악을 깎지 않는 짝.
3. **TMF는 SOXL 신호에 사면 안 된다.** SOX 저점 월 매수 12개월 중앙 0.84배, 6회 중 4회 손실. 채권은 주식 저점에서 고점(2020)이거나 같이 빠진다(2022). TLT 위치가 바닥권인 것은 맞지만 기준은 금리 고점 확인(NAIL 원칙)이다.
4. **사이클 위상 지도(최종 정의).** 확정된 저점 0·고점 100, 아직 끝나지 않은 구간은 그 자산의 과거 사이클 진폭 중앙값 대비 진행률. 2026-10 현재: 고점권 100 = E&P·구리·브라질 / 반도체 40(고점 뒤 4개월, 내려오는 중) / 주택 27(저점 근접) / 저점권 16~20 = 은·금광주·장기국채.
5. **지금 살 사이클은 없다.** 바닥권 셋(은·금광주·국채) 중 금광주만 월봉 저점(2026-07)이 확정됐고, 은은 아직 내려오는 중, 국채는 36개월째 바닥 다지기. 반도체는 과거 낙폭의 절반(월봉 기준, 일봉으로는 그보다 덜)만 왔다.

## 2. 저점 동시성 연구 v1

### 2-1. 질문과 규칙

반도체 저점(SOXL 60점 발화: 2016-02-11 / 2018-12-24 / 2020-03-12 / 2022-09-26 / 2025-04-03, 저점보다 0~18일 선행)에 다른 사이클 자산도 같이 바닥을 찍는가? 찍는다면 그날 자금을 어디에 나눠야 반등 배수가 최대인가?

- 자료: digrin 월말 조정종가(1배 20종, 레버리지 15종). SOX 저점 월은 프로젝트 일봉 확정값(2008-11 / 2011-10 / 2016-02 / 2018-12 / 2020-03 / 2022-10 / 2025-04).
- 사전 고정 규칙: 공통 저점 창 안 월말 최저 = 그 자산의 저점 월. SOX 저점 월과 ±2개월 = 동시, 3~6개월 = 지연/선행, 7개월+ = 시차 불일치.
- **사후 변경 2건(명기):** ① E7(2025-04) 추가 — XBI 1종만 받은 뒤 ② "창 밖에 더 낮은 값이 있으면 불일치" 폐기 → 월말 값이라 2020-03 V자 급락이 오판돼, 창 안 저점의 1년 고점 대비 낙폭 −15% 미만을 "얕음"으로 분류. 동시율을 느슨하게 만드는 방향의 변경이라 과대평가 가능.
- 추가 지표: **SOX 저점 월말에 샀을 때 12·24개월 배수**(실전 질문에 맞는 지표).

## 3. 사이클 위상 지도 — 정의를 세 번 고친 과정

주인님 요청: v2 목록의 사이클을 **한 그래프에 겹쳐**, 가로축 2010~2026, 세로축 저점~고점으로, 지금 어느 사이클이 고점·저점·오르는 중인지 보이게.

### 3-1. 버전 1 — 산업별 가격 패널 (폐기)
사이클마다 한 장씩 월봉 로그가격을 7개월 중심평균으로 다듬고 30% 지그재그로 고점·저점 표시. **단일 주가 그림이라 겹쳐 비교가 안 됨** → 폐기.

### 3-2. 버전 2 — 5년 범위 위치 (폐기, 주인님 지적)
세로축 = 그 달 가격이 직전 60개월 범위 안 어디인지(0 = 5년 최저, 100 = 5년 최고). **오류:** ITB처럼 14년간 저점이 계속 높아진 자산은 2018·2020·2022의 진짜 사이클 저점(−35~−39%)도 5년 최저를 못 깨 40~60으로만 찍혔다. 추세가 있는 자산에서는 저점이 안 보인다.

### 3-3. 버전 3 — 진행 중 극값 기준 위상 (폐기, 주인님 지적)
확정 저점 0·확정 고점 100, 마지막 구간은 "고점 이후 지금까지의 최저"를 0으로. **오류:** 고점에서 4개월 내려온 반도체가 "저점 0"으로 찍혔다. 고점 뒤 최저가 곧 사이클 저점이 아니다 — 과거 반도체 고점→저점 낙폭은 −41~−80%인데 지금 −21%. 이 정의로는 "저점권 = 매수"가 되어 틀린 신호를 준다.

### 3-4. 버전 4 — 최종 정의

## 4. 이번 세션에서 얻은 원칙

1. 사이클 판정은 레버리지가 아니라 1배로 한다(감쇠로 고점·저점이 어긋남).
2. "5년 범위 위치"는 추세 자산의 저점을 못 본다. "고점 뒤 최저"도 저점이 아니다. 저점 여부는 **그 자산의 과거 진폭·기간 대비 진행률**과 **산업 고유 저점 지표**로 판단한다.
3. 저점은 사건, 고점은 과정. 고점은 공급 반응·시장 구조(신규 레버리지 출시·섹터 로테이션)·차트 세 층을 겹친다.
4. 공통 저점에서 분산은 수익을 깎는다. SOXL 단독 또는 SOXL+NAIL(30% 이하, R9 조건부).
5. 지정학형 급등(E&P 2026·금 2026)은 수요 사이클 고점이 아니라 사건 프리미엄이며 사태 해소가 고점이다.
6. 규칙은 자료를 보기 전에 고정하고, 사후 변경은 이유와 함께 명기한다(이번 세션 변경: 동시성 연구 2건, 위상 지도 정의 3회).

## 부록 A. 위상 지도 핵심 코드 (`cyclemap2.py` 발췌)

~~~python
def zigzag(s, th):
    """월봉 지그재그. th 이상 되돌림마다 고점(H)/저점(L) 확정. 반환 [(index,'H'|'L')], 방향, 진행 중 최고·최저 index"""
    v = s.values; piv = []; i_max = i_min = 0; dirn = 0
    for i in range(1, len(v)):
        if dirn == 0:
            if v[i] > v[i_max]: i_max = i
            if v[i] < v[i_min]: i_min = i
            if v[i] <= v[i_max]*(1-th): dirn = -1; piv.append((i_max,'H')); i_min = i
            elif v[i] >= v[i_min]*(1+th): dirn = 1; piv.append((i_min,'L')); i_max = i
        elif dirn == 1:
            if v[i] > v[i_max]: i_max = i
            if v[i] <= v[i_max]*(1-th): piv.append((i_max,'H')); dirn = -1; i_min = i
        else:
            if v[i] < v[i_min]: i_min = i
            if v[i] >= v[i_min]*(1+th): piv.append((i_min,'L')); dirn = 1; i_max = i
    return piv, dirn, i_max, i_min

def phase_series(s, th):
    """확정 구간: 저점 0 ~ 고점 100(로그 비율). 마지막 미확정 구간: 과거 확정 구간 진폭 중앙값 대비 진행률."""
    lg = np.log(s.values); piv, dirn, i_max, i_min = zigzag(s, th)
    out = np.full(len(lg), np.nan); downs, ups, dmon, umon = [], [], [], []
    for k in range(len(piv)-1):
        (a, ta), (b, tb) = piv[k], piv[k+1]
        lo, hi = (lg[a], lg[b]) if ta == 'L' else (lg[b], lg[a]); rng = max(hi-lo, 1e-9)
        for i in range(a, b+1): out[i] = 100*(lg[i]-lo)/rng
        if ta == 'H': downs.append(lg[a]-lg[b]); dmon.append(b-a)
        else: ups.append(lg[b]-lg[a]); umon.append(b-a)
    ref = dict(down=np.median(downs), up=np.median(ups), dmon=np.median(dmon), umon=np.median(umon))
    a, ta = piv[-1]
    if ta == 'H':   # 고점 뒤 하락 중: 과거 낙폭 중앙값 대비
        for i in range(a, len(lg)): out[i] = 100*(1 - (lg[a]-lg[i])/ref['down'])
    else:           # 저점 뒤 상승 중: 과거 상승 중앙값 대비
        for i in range(a, len(lg)): out[i] = 100*min(1, (lg[i]-lg[a])/ref['up'])
    return pd.Series(np.clip(out, 0, 100), index=s.index), piv, ref
~~~
