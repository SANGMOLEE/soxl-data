**지금까지 연구에서 얻은 원칙 가운데 이번 작업에 그대로 쓰는 것**

2. MicroSectors 상품은 ETN이다(발행사 신용위험, 조기상환 권리). 장기 사이클 매매에는 맞지 않아 대표 티커에서 뺀다.
3. Direxion이 3배에서 2배로 낮춘 상품(ERX, GUSH, NUGT, JNUG, INDL, BRZU, CWEB, CHAU, FNGG)은 옛 자료에 3배로 나와 있다. 백테스트에서는 배수 변경일을 구조 단절로 다룬다.
4. 결과를 보기 전에 판정 규칙을 고정한다(이번 판정 규칙은 §3에 적은 그대로이며 자료를 받기 전에 정했다).

## 3. 판정 방법 (자료를 받기 전에 고정한 규칙)

| 지표 | 정의 |
|---|---|
| 5년 위치 | 최근 60개월(현재 포함) 월말 값의 최저~최고 사이에서 현재 위치. 0 = 5년 최저, 100 = 5년 최고. 이 프로젝트의 "0에 가까울수록 저점" 방향과 같다 |
| 5년 고점 대비 | 현재 ÷ 60개월 최고 − 1 |
| 3년 저점 대비 | 현재 ÷ 36개월 최저 − 1 |
| 추세 | 10개월 이동평균선(약 200거래일). **상승** = 가격이 선 위 + 선이 3개월 전보다 높음. **하락** = 가격이 선 아래 + 선이 낮아짐 |

| 추세 | 5년 위치 | 단계 |
|---|---|---|
| 상승 | 85 이상 | ④ 고점권 |
| 상승 | 40 이하 | ② 바닥 통과·상승 초기 |
| 상승 | 그 사이 | ③ 상승 중반 |
| 하락 | 20 이하 | ① 바닥권(하락 지속) |
| 하락 | 20 초과 | ⑤ 고점 통과·하락 중(70 이상이면 "고점 직후 꺾임"으로 표기) |
| 가격은 선 위, 선은 하락 | 40 이하 | ② 바닥 통과 시도(확인 전) |
| 가격은 선 위, 선은 하락 | 40 초과 | ③ 하락 추세 속 반등 |
| 가격은 선 아래, 선은 상승 | 70 이상 | ⑤ 고점권 조정(꺾임 의심) |
| 가격은 선 아래, 선은 상승 | 70 미만 | ③ 상승 추세 속 조정 |

- 사이클 판정은 레버리지 상품이 아니라 1배 기준 ETF로 했다. 레버리지 상품은 횡보장 감쇠 때문에 고점·저점이 기초자산과 어긋난다.
- 표의 **※**는 가격이 10개월선과 ±2% 안에 있어 10월 말 종가에 따라 단계가 바뀔 수 있는 곳이다.

## 4. 산업별 현재 위치 (단계 순, 같은 단계 안에서는 5년 위치가 높은 순)

반도체·주택건설·한국·비트코인은 각 연구 세션에서 판정하므로 이 표에서 뺐다.

## 7. 한계와 확인하지 못한 것

1. **검증하지 않은 간이 규칙이다.** 5년 위치와 10개월선은 과거 사이클로 맞춰 본 적이 없다. "몇 점이면 산다"를 정하려면 SOXL·NAIL처럼 산업별로 따로 시험해야 한다.
2. **10월은 미완성 월이다.** ※ 표시 10곳(통신·유럽·소재·경기소비재·신흥국·운송·지역은행·소형주·중형주·제약)은 10월 말 종가로 단계가 바뀔 수 있다.
3. **월말 값이라 일중 고점·저점보다 얕다.** 하락 중 가장 깊었던 날의 낙폭은 표보다 크다.
4. **조정가에는 분배금이 들어 있다.** 배당이 큰 업종(리츠·유틸리티·에너지)은 가격만 볼 때보다 고점에 가깝게 나온다.
5. **원유·천연가스 ETF는 선물 상품이다.** 현물 가격 사이클과 위치가 다를 수 있다.
6. **자료 결함.** WEBL 시세 2023-10~2026-09 공백. UGLD·USLV는 Direxion 신규 상품인데 시세 사이트에는 같은 이름의 옛 상장폐지 ETN만 있어 이력을 확보하지 못했다. CURE는 시세 사이트 10월 값이 멈춰 있어 일봉 값으로 바꿨다. DPST·URE는 10월 행이 없어 9월 기준이다. 레버리지 상품의 10월 값은 10/13~10/16 사이에 찍혀 날짜가 조금씩 다르다.
7. **범위 밖.** 국내 상장 레버리지 ETF(세금 면에서 유리할 수 있음, 7월에 별도 세션으로 미룸), 레버리지 상품이 없는 산업(해운·철강·구리·농산물), 개별 종목 레버리지(SKHL 등)는 판정하지 않았다.
8. **신규 상품 누락 가능성.** Direxion 목록은 10/17에 확인했지만, ProShares·MicroSectors는 8/19 목록 기준이다.

## 8. 부록 — 판정 코드 (`cycle_stage.py`)

입력은 `raw/{티커}.csv`(열: `month,adj`)다. 2026-10-17에 이 코드로 §4 표를 만들었다(기존 연구 대상 행은 표에서 뺐다).

~~~~python
# 산업 사이클 위치 판정기 v1 (2026-10-17, 결과를 보기 전에 규칙 고정)
# 입력: raw/{TICKER}.csv (month,adj) — digrin 월말 조정종가(분배금 포함). 마지막 달(2026-10)은 10/16 무렵까지의 미완성 월.
# 규칙
#   P      = 마지막 월 값
#   R5     = 최근 60개월(현재 포함) 범위 안 위치 (P−최저)/(최고−최저)×100   0 = 5년 최저, 100 = 5년 최고
#   DD5    = P / 60개월 최고 − 1,  DDATH = P / 전체(2016~) 최고 − 1
#   UP3    = P / 36개월 최저 − 1
#   추세   = 10개월 이동평균 SMA10.  상승: P > SMA10 이고 SMA10 ≥ 3개월 전 SMA10
#                                   하락: P < SMA10 이고 SMA10 < 3개월 전 SMA10
#                                   그 밖: 'P위·선하락'(하락 추세 속 반등) 또는 'P아래·선상승'(상승 추세 속 조정)
#   단계   = 상승  & R5 ≥ 85            → ④ 고점권(상승 지속)
#            상승  & R5 ≤ 40            → ② 바닥 통과·상승 초기
#            상승  & 그 밖              → ③ 상승 중반
#            하락  & R5 ≤ 20            → ① 바닥권(하락 지속)
#            하락  & 그 밖              → ⑤ 고점 통과·하락 중
#            P위·선하락 & R5 ≤ 40       → ② 바닥 통과 시도(확인 전)
#            P위·선하락 & 그 밖         → ③ 반등(하락 추세 속)
#            P아래·선상승 & R5 ≥ 70     → ⑤ 고점권 조정(꺾임 의심)
#            P아래·선상승 & 그 밖       → ③ 상승 중 조정
import sys, glob, os, pandas as pd, numpy as np

def stage(df):
    s = df.set_index('month')['adj'].astype(float)
    s = s[~s.index.duplicated(keep='last')].sort_index()
    P = s.iloc[-1]; w60 = s.iloc[-60:]; w36 = s.iloc[-36:]
    hi60, lo60 = w60.max(), w60.min()
    R5 = 100 * (P - lo60) / (hi60 - lo60) if hi60 > lo60 else np.nan
    sma = s.rolling(10).mean(); m_now, m_3 = sma.iloc[-1], sma.iloc[-4]
    if P > m_now and m_now >= m_3: tr = '상승'
    elif P < m_now and m_now < m_3: tr = '하락'
    elif P >= m_now: tr = 'P위·선하락'
    else: tr = 'P아래·선상승'
    if tr == '상승':   st = '④ 고점권' if R5 >= 85 else ('② 바닥 통과·상승 초기' if R5 <= 40 else '③ 상승 중반')
    elif tr == '하락': st = '① 바닥권(하락 지속)' if R5 <= 20 else '⑤ 고점 통과·하락 중'
    elif tr == 'P위·선하락': st = '② 바닥 통과 시도(확인 전)' if R5 <= 40 else '③ 반등(하락 추세 속)'
    else: st = '⑤ 고점권 조정(꺾임 의심)' if R5 >= 70 else '③ 상승 중 조정'
    r12 = P / s.iloc[-13] - 1 if len(s) > 13 else np.nan
    return dict(last=s.index[-1], P=P, R5=R5, DD5=P / hi60 - 1, DDATH=P / s.max() - 1, UP3=P / w36.min() - 1,
                R12=r12, SMA10_gap=P / m_now - 1, SMA10_slope3=m_now / m_3 - 1, trend=tr, stage=st,
                hi60_m=w60.idxmax(), lo60_m=w60.idxmin(), lo36_m=w36.idxmin(), ath_m=s.idxmax(), n=len(s))

if __name__ == '__main__':
    d = sys.argv[1]; rows = []
    for f in sorted(glob.glob(os.path.join(d, '*.csv'))):
        t = os.path.basename(f)[:-4]
        if t.startswith('lev_'): continue
        df = pd.read_csv(f, dtype={'month': str})
        if len(df) < 61: print('short', t, len(df)); continue
        r = stage(df); r['ticker'] = t; rows.append(r)
    R = pd.DataFrame(rows).set_index('ticker')
    pd.set_option('display.width', 250)
    print(R[['last','P','R5','DD5','DDATH','UP3','R12','SMA10_gap','SMA10_slope3','trend','stage','hi60_m','lo60_m','lo36_m','n']].round(3).to_string())
    R.to_csv(os.path.join(d, '..', 'stage_result.csv'))
~~~~
