### 질문 1. "하락기엔 현금, 반등 때 재매수" 방식보다 BITU 상시 보유가 낫다는 게 말이 되는가

말이 안 됩니다. 그렇게 결론 낸 것도 아닙니다.
- 표의 "2배 상시 보유" 행은 주인님 전략이 아닙니다. 하락기 현금 보유가 얼마나 중요한지 보이려고 넣은 **비교용 기준선**입니다.
- 그런데 v2에서 이 행을 결론 표에 같이 올려 오해를 드렸습니다. 제 서술 잘못입니다.

2015~2020 비트코인 구간을 국면별로 쪼개면, BITU 상시 보유가 이긴 원인이 한 곳에 몰려 있습니다.

| 국면 | BTC 현물 | 사이클 틀(하락기 현금) + BITU | BITU 상시 |
|---|---|---|---|
| 2015-03~2017-05 상승기 | 7.84배 | 18.71배 | 20.63배 |
| **2017-05-31~2017-12-18 (2017 폭등)** | 8.36배 | **1.00배 (현금)** | **38.24배** |
| 2017-12~2018-04 하락기 | 0.46배 | **1.00배 (현금)** | 0.13배 |
| 2018-04~2018-12 가짜 저점 진입→무효화 이탈 | 0.40배 | **0.19배** | 0.11배 |
| 2018-12~2020-04 | 2.06배 | 1.03배 | 1.21배 |

- 하락 국면에서는 **매번 현금 방식이 이겼습니다**(1.00배 vs 0.13배, 0.19배 vs 0.11배). 주인님 판단이 맞습니다.
- 지게 만든 것은 단 하나입니다. 문서의 "고점창(반감기+300~600일) 안에서 BTC -10% → 최종 매도" 규칙이 **2017-05-27, 고점창이 열리자마자** 발동했습니다. 그 뒤 BTC 8.4배(BITU 38배) 폭등 동안 현금이었습니다.
- 즉 "하락기 현금" 개념이 실패한 것이 아니라 **고점 판정 규칙이 실패**한 것입니다. 기존 전략서 §6-2가 "가장 큰 미해결 약점"이라고 적은 바로 그 부분입니다.
- 2020~2026 비트코인 구간에서는 같은 사이클 틀이 100배로, BITU 상시 보유(4.7배)를 압도했습니다.

### 질문 2. SOLT 보유가 현물보다 낮다는 게 말이 되는가

상승기 대부분에서는 SOLT가 현물보다 훨씬 높습니다.
- 2022-12~2024-03 저점→고점: SOLT 105배 vs 현물 19.6배
- 실시간 상승기 2023-01~2025-02: SOLT 10.4배 vs 현물 8.7배

낮게 나온 곳은 두 경우뿐입니다.
1. 하락기까지 들고 간 "2배 상시 보유" 기준선. 주인님 전략이 아닙니다.
2. 2020-04~2021-03 구간 하나. 쪼개 보면 다음과 같습니다.

| 2020 구간 | SOL 현물 | SOLT |
|---|---|---|
| 상승① 2020-04-13→08-31 (0.78→4.78달러) | 6.15배 | 9.30배 |
| **SOL만 -75% (08-31→12-23, 같은 기간 BTC는 10k→23k 상승)** | 0.25배 | **0.02배** |
| 상승② 12-23→2021-03-05 (1.21→12.6달러) | 10.46배 | 46.62배 |
| 전체 | 16.2배 | 10.3배 |

- 2배 상품은 -75% 하락에서 -98%가 됩니다. 그 뒤 46배를 올라도 그 구멍을 다 메우지 못합니다.
- 이 구간 SOL 변동성은 연 181%였습니다. 비용 없이 매일 재조정하는 이상적인 2배도 15.6배로 현물 16.2배보다 낮습니다. 레버리지 손실은 변동성의 제곱에 비례하기 때문입니다.
- 자료 오류는 없었습니다. BITU 가격은 분배금 반영값이고(2×IBIT와 하루 3% 넘게 어긋난 날 0일), SOL 급변일은 실제 사건일입니다.
- 이 구간은 오히려 **주인님 전략의 로테이션 규칙이 옳다는 근거**입니다. BTC는 오르는데 SOL만 무너질 때 SOL/BTC 모멘텀이 음수로 바뀌어 BITU로 옮겨 갑니다. 같은 구간 로테이션은 179배였습니다(SOLT 보유 10.3배).

### 덧붙임
- 제가 추천한 규칙들은 모두 하락기에 현금입니다. 혼합형 평균 노출은 46%이고, BTC가 이동평균 아래면 0%입니다.
- "현재 BITU 20%"는 상시 보유 지시가 아니라 규칙이 내린 판정입니다. 2026-08-19 저점 확인으로 사이클 틀이 켜져 있고, BTC가 100·150일선 위에 있기 때문입니다.
- 주인님 기존 전략서 엔진도 같은 이유로 지금 BITU 100%입니다.

**실시간으로는 그렇지 않다.**

  - 2024~2026 누적: -62%
- 실시간으로 판정한 상승기 **안에서만** 비교해도 결과가 엇갈린다.
  - 사이클2(2023-01~2025-02): SOLT 보유 10.4배 > 추세 필터 운용 8.3배. 그러나 SOLT/BITU 로테이션 12.2배보다는 낮았다.

# 2부. 수익률 최적화 연구

## 2-1. 방법

- **시험 구간 4개.** 한 구간에서 고른 규칙이 다른 구간에서도 통하는지 본다.
  - SOL 사이클1: 2020-04-13~2022-12-30. 상장 전 합성 SOLT를 쓴다.
  - SOL 사이클2: 2023-01-02~2026-10-30. 2025-03 이후는 실제 SOLT다.

## 2-8. ★ 혼합형 운용 규칙 (매일, KST)

1. **09:00 KST 이후** BTC·SOL 일봉 종가(UTC 자정)를 확정한다.
2. **사이클 틀 상태(0/1)를 갱신한다.**
   - 켜짐: BTC가 직전 사이클 고점 대비 -35% 이하로 내려간 뒤, 100일선을 60일 이상 연속 밑돌다 위로 마감
   - 꺼짐(무효화): 그 약세장 저점을 종가로 이탈
   - 꺼짐(최종 매도): 반감기 +300~600일 창 안에서 BTC가 진입 후 고점 대비 -10%
   - 현재 켜짐(2026-08-19부터). 다음 고점창은 2029-02~2029-11(반감기 2028-04 추정 기준)이다.
3. **BTC 20일선 상태(0/1):** 종가가 20일선 위로 마감하면 1, 아래로 마감하면 즉시 0.
4. **앙상블 A:** BTC 종가가 30·50·75·100·150일선 각각의 위에 있는지 같은 방식(아래 마감 즉시 0)으로 판정한다. 위에 있는 개수를 5로 나눈다.
5. **노출 비율** = ½ × (사이클 틀 × 20일선 상태) + ½ × 앙상블 A. 10% 단위로 0~100%다.
6. **도구:** SOL/BTC 비율의 20일 변화율이 0보다 크면 SOLT, -5%보다 작으면 BITU, 그 사이면 직전 도구를 유지한다.
7. **체결:** 그날 미국 정규장 안에서 목표 비중으로 맞춘다. 겨울시간 23:30~06:00 KST이며, 가능하면 마감 직전(05:50 KST 전후). 하루라도 늦으면 성과가 크게 떨어진다.
8. **현재(10/31 종가):** 사이클 틀 1 × 20일선 0 = 0, 앙상블 A = 2/5 = 0.4. 노출 = ½×0 + ½×0.4 = **20%**, 도구 **BITU**. → BITU 20%, 현금 80%.

def inst_returns(cal, drag_s=.20, drag_b=.16):
    S=V.instrument("SOLT",cal,drag_s,True); B=V.instrument("BITU",cal,drag_b,True)
    return pd.DataFrame({"SOLT":S.pct_change().fillna(0),"BITU":B.pct_change().fillna(0),
                         "SOL":SOL.reindex(cal).pct_change().fillna(0),"BTC":BTC.reindex(cal).pct_change().fillna(0)})
def sim(W, R, cost=.001):
    """W: 비중 DataFrame(index=거래일, cols⊂R.cols) — t일 종가에 정해 t+1일 수익에 적용"""
    W=W.reindex(R.index).fillna(0.0)
    held=W.shift(1).fillna(0.0)
    gross=(held*R[W.columns]).sum(axis=1)
    turn=W.diff().abs().sum(axis=1).fillna(W.iloc[0].abs().sum())
    net=(1+gross)*(1-cost*turn)-1
    return (1+net).cumprod()
def at(sig, cal):
    """크립토 달력 신호를 거래일 t에 '전일 크립토 종가 기준'으로 샘플"""
    return sig.reindex(cal - pd.Timedelta(days=1)).set_axis(cal)
def st(e,a=None,b=None):
    e=(e[a:b] if (a or b) else e).dropna(); tot=e.iloc[-1]/e.iloc[0]; yrs=(e.index[-1]-e.index[0]).days/365.25
    dd=(e/e.cummax()-1).min(); return dict(ret=tot-1, mult=tot, cagr=tot**(1/yrs)-1, mdd=dd)
def f(d): return f"{d['ret']:+,.0%} / {d['mdd']:.0%}"

def runlen(b):
    b=b.astype(int); return b.groupby((b==0).cumsum()).cumsum()
def trend_state(px, n, k):
    """진입: 종가>MA_n, 이탈: MA_n 아래 k일 연속. 크립토 달력 상태(1/0)"""
    ma=px.rolling(n).mean(); above=px>ma; rb=runlen(px<ma)
    s=pd.Series(np.nan,index=px.index); s[above]=1; s[rb>=k]=0
    return s.ffill().fillna(0)
def cycle_state(exit_mode="final", trail=None, n_re=200, invalid=True):
    """문서 진입(약세 -35% 후 100일선 60일 하회→회복) 이후 보유. exit_mode: final(고점창 -10%만), b200(BTC 200일선 5일 하회→현금, 위로 회복 시 재진입), s200(SOL 기준)"""
    b=BTC; ma100=b.rolling(100).mean(); rb100=runlen(b<ma100)
    rec=(b>ma100)&(rb100.shift(1)>=60)
    ma200=b.rolling(200).mean(); rb200=runlen(b<ma200)
    sma=SOL.rolling(200).mean(); rs200=runlen(SOL<sma)
    st=pd.Series(0.0,index=b.index); phase="WAIT"; hi=b[:"2014-12-31"].max(); bear=False; peak=None; on=False; blo=None; ref=None; bhi=None
    for d in b.index:
        x=b[d]; hi=max(hi,x)
        if phase=="WAIT":
            if (not bear) and x<=hi*0.65: bear=True; blo=x; bhi=hi
            elif bear and x>bhi: bear=False; blo=None      # v2.1 수정: 약세 성립 당시 고점을 넘는 신고가 → 약세 판정 해제(낡은 저점 방지)
            elif bear: blo=min(blo,x)
            if bear and rec[d]: phase="UP"; peak=x; on=True; ref=blo
        else:
            peak=max(peak,x)
            hal=max([h for h in HALV if h<=d]); intop=300<=(d-hal).days<=600
            if invalid and x<ref:   # 무효화: 진입 근거였던 약세장 저점 이탈 → 대기로
                phase="WAIT"; bear=True; blo=x; on=False; bhi=hi
            elif intop and x<=peak*0.9:
                phase="WAIT"; bear=False; hi=peak; on=False
            elif exit_mode=="b200":
                if on and rb200[d]>=5: on=False
                elif (not on) and x>ma200[d]: on=True
            elif exit_mode=="s200":
                if on and rs200[d]>=5: on=False
                elif (not on) and SOL[d]>sma[d]: on=True
        st[d]=1.0 if (phase=="UP" and on) else 0.0
    return st
def rot_choice(n=20, lo=-0.05, hi=0.0):
    """SOL/BTC n일 변화율 히스테리시스: 1=SOL쪽, 0=BTC쪽"""
    r=SOL/BTC; m=r/r.shift(n)-1; s=pd.Series(np.nan,index=m.index); s[m>hi]=1; s[m<lo]=0
    return s.ffill().fillna(1)
def vol_scale(thr, win=30):

def weights(cal, on, mode="SOLT", rot=None, lev_hi=None):
    """on: 크립토 달력 0/1. mode: SOLT / HALF / ROT / VOL"""
    o=at(on,cal).fillna(0)
    W=pd.DataFrame(0.0,index=cal,columns=["SOLT","BITU"])
    if mode=="SOLT": W["SOLT"]=o
    elif mode=="HALF": W["SOLT"]=0.5*o
    elif mode=="ROT":
        c=at(rot,cal).fillna(1); W["SOLT"]=o*c; W["BITU"]=o*(1-c)
    elif mode=="VOL":
        h=at(lev_hi,cal).fillna(0); W["SOLT"]=o*(0.5+0.5*h)
    return W

def bear_gate(dd=0.35, invalid=True):
    """약세장 잠금: 고점 대비 -dd 이면 잠금 → 문서 저점확인(100일선 60일 하회 후 회복) 시 해제 → 해제 후 잠금 당시 저점 이탈 시 재잠금. 고점창 최종매도 없음."""
    b=BTC; ma100=b.rolling(100).mean(); rb100=runlen(b<ma100); rec=(b>ma100)&(rb100.shift(1)>=60)
    g=pd.Series(1.0,index=b.index); locked=False; pk=b.iloc[0]; lo=None; ref=None
    for d in b.index:
        x=b[d]
        if not locked:
            pk=max(pk,x)
            if x<=pk*(1-dd): locked=True; lo=x
            elif invalid and ref is not None and x<ref: locked=True; lo=x
        else:
            lo=min(lo,x)
            if rec[d]: locked=False; pk=x; ref=lo
        g[d]=0.0 if locked else 1.0
    return g
