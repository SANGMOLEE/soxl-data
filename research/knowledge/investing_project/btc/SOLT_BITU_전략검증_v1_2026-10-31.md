## 0. 결론 (한 장)

**판정: 규칙은 매일 기계적으로 따라 할 수 있다. 그러나 전략서의 성적(+11,007%, 한 사이클 +2,202%)은 실제로 기대할 수 있는 수치가 아니다.**
- 실제로 체결 가능한 조건으로 다시 돌리면 한 사이클(2022-11-21~2026-10-31) 성적은 **+499%, 최대낙폭 -62%**다.
- 위험 대비 성적(연복리÷최대낙폭)은 **0.93**이다. 같은 기간 솔라나 현물 보유 0.92, 비트코인 현물 보유 0.93과 같다. 위험 대비 우위가 확인되지 않는다.

성적이 부풀려진 원인 네 가지:
1. **문서와 코드가 다르다.** 수치는 코드에서 나왔는데, 코드는 문서에 적힌 규칙 중 6곳을 다르게 실행한다. 문서 문구대로 돌리면, 다른 조건이 같아도 한 사이클 +2,243%가 +1,218%로 줄어든다.
2. **체결할 수 없는 가격으로 거래했다.** 크립토는 주 7일 거래되지만 ETF는 평일에만 거래된다. 원 엔진은 상장 후 구간에서 토·일요일 신호를 금요일 ETF 종가로 체결했고, 상장 전 합성 구간에서는 주말에도 거래했다. 미국 거래일 체결로만 바꿔도 +2,243%가 +1,367%가 된다.
3. **상장 전 합성 ETF에서 레버리지 비용이 빠졌다.** 원 엔진은 보수(연 0.95%·1.95%)만 뺐다. 실측한 실제 괴리는 BITU 연 **-16.0%**, SOLT 연 **-20.2%**다.
4. **수익 전부가 한 번의 6개월에서 나왔다.** 2023-10~2024-03(솔라나 8.5배)에 전략은 13~50배를 벌었다. 나머지 기간을 합치면 원금의 0.39~0.47배로 줄었다.

강건성:
- 저점 확인 기준 "100일선 60일 하회"를 **75일로 바꾸면 한 사이클 성적이 +2%**가 된다. 2023-01 진입 신호의 하회 기간이 65일이었기 때문이다.
- 파라미터를 하나씩 흔든 54개 변형(문서 규칙·현실 조건) 가운데 솔라나 현물 보유를 이긴 것은 **6%**다.

표본 외 검증(2015~2020 비트코인, 솔라나 규칙 제외, 뼈대만):
- 문서 규칙: +1,860%, 최대낙폭 -70%
- 비트코인 현물 보유: +2,218%, 최대낙폭 -83%
- 위험 대비로는 비슷하다(1.09 vs 0.98). 원 엔진 규칙은 2020년 3월 폭락에서 -78%를 맞았다(+620%, 최대낙폭 -92%).

실매매 조건:
- BITU는 국내에서 매수된 기록이 있다.
- SOLT의 국내 증권사 취급 여부는 이번에 확인하지 못했다.
- 해외 레버리지 ETP에는 사전교육 의무가 있고, 처음 거래하는 사람은 기본예탁금 1,000만원이 필요하다(기존 거래 경험자는 면제).
- 세금은 해외주식 양도세 22%다. 해마다 실현되므로 한 사이클 +499%는 세후 약 +372%가 된다.

**쓰신다면:** ① 문서와 코드를 먼저 일치시키십시오. ② 자금의 일부로만 운용하십시오. ③ 다음 사이클 신호를 미리 기록해 두고 사후 판정하는 전방 검증을 거치십시오.

참고: 같은 신호를 코인 현물 1배(국내 거래소, 24시간 체결)로 운용하면 한 사이클 +630%, 최대낙폭 -36%로 2배 ETF안보다 낫다. 단 이것도 같은 표본 안의 결과다.

1. **원 엔진 재현.** 기본값으로 실행해 전략서 수치(+11,007% / 한 사이클 +2,202% / 최대낙폭 -77% / 거래 76건)가 그대로 나오는지 확인했다. 그대로 나왔다.

3. **해석과 현실 조건 분리.** 규칙 해석(코드 vs 문서)과 체결 조건(7일 체결 vs 미국 거래일, 비용)을 스위치로 나눠 하나씩 바꿔 보았다.
4. **강건성 시험.** 파라미터 민감도, 수익 집중도, 표본 외 구간(2015~2020 비트코인), 단순 기준선과의 비교를 했다.
5. **실매매 조건 확인.** 상품 구조, 국내 규제, 세금, 유동성을 2026-10-31 기준으로 확인했다.

## 3. 체결 현실성

### 3-1. 주말과 시차 (시각은 모두 KST)
- 신호의 기준인 크립토 일봉 종가는 **09:00 KST**에 확정된다(UTC 자정).
- ETF 종가는 서머타임 중 **05:00 KST**다. 2026-11-02(월) 장부터는 겨울시간이라 정규장이 23:30~06:00 KST, 종가가 **06:00 KST**다.
- 평일 체결: 전일 신호를 그날 미국 종가에 체결하면 약 20시간의 간격이 있어 문제가 없다.
- 원 엔진의 주말 처리: 상장 후 구간에서 ETF 가격을 직전 값으로 채웠다. 그래서 토요일 체결은 신호보다 4시간 앞선 금요일 종가로, 일요일 체결은 약 28시간 앞선 가격으로 이뤄졌다. 상장 전 합성 구간은 주말에도 그날 크립토 종가로 체결했다. 실제 ETF로는 불가능한 거래다.
- 미국 거래일에만 체결하도록 바꾸었다. 주말 신호는 월요일 종가에 체결하고, 상장 전 합성 ETF는 직전 거래일 대비 수익률의 2배로 만들었다. 결과(원 엔진 규칙):

| 연도 | 7일 체결 | 미국 거래일 체결 |
|---|---|---|
| 2023 | +1,217% | +1,188% |
| 2024 | **+94%** | **+14%** |
| 한 사이클 | +2,243% | +1,367% |

체결이 하루이틀 밀리는 것만으로 2024년 성적이 +94%에서 +14%로 바뀌었다. 전략의 경로 의존성이 매우 크다는 뜻이다.

- 2020년부터 재면 순위가 뒤집혀 단순 규칙이 압도한다. 2020~21년 솔라나 250배 상승을 단순 규칙은 탔고, 전략은 약세장 조건 때문에 2021-07까지 대기했기 때문이다. 다만 그 시기에는 솔라나 2배 상품이 없었으므로 이 숫자 자체는 실현할 수 없었다.
- 핵심은 **어느 구간을 재느냐에 따라 순위가 뒤집힌다**는 점이다. 사이클 표본이 1~2개뿐이라 우열을 단정할 수 없다.

### 6-2. 국내 매매 조건

**확인된 것**
- BITU는 상장 직후(2024-04) 국내 투자자 순매수 상위에 올랐다. 국내 증권사에서 거래된 상품이다.
- 금융위는 2024-01 미국 현물 비트코인 ETF의 중개는 불허했다. 반면 선물형 비트코인 ETF는 "현행처럼 거래"한다는 입장이었다.
- 해외 레버리지 ETP 사전교육이 의무화되었다(2025-12-15~). 기존 해외 레버리지 거래 경험자는 면제다.
- 해외 레버리지 ETF·ETN을 **처음** 거래하는 개인은 기본예탁금 1,000만원이 필요하다(2026-05-22~). 외화예수금도 인정되며, 기존 거래 경험자는 제외된다.

**확인하지 못한 것 (주인님 증권사 앱에서 직접 확인 필요)**
- SOLT가 주인님이 쓰시는 증권사에 상장 종목으로 열려 있는지.
- 2026-08부터 "국내외 단일종목 레버리지"에 적용된 기본예탁금 3,000만원(대용증권 불인정) 규정이 BITU·SOLT 같은 단일 코인 2배 ETF에도 적용되는지. 일부 국내 ETF 정보 사이트는 BITU를 "단일 종목 일간 2배 추종 레버리지"로 분류하고 있어 해석 여지가 있다.

**세금**
- 해외주식 양도세 22%(연 250만원 공제)다. 같은 해 다른 해외주식과 손익을 통산할 수 있지만 이월은 없다.
- 이 전략은 해마다 대부분 실현되므로 복리가 깎인다. 한 사이클 +499%는 세후 약 +372%(근사)다.
- 코인 현물로 운용하면 가상자산 과세(22%, 250만원 공제)가 **2027-01-01**부터 시행될 예정이다. 2026 세제개편안에 유예가 없다. 다만 법 개정 여지는 남아 있다.

### 6-3. 운용 실무
- 백테스트는 "전일 신호 → 당일 ETF 종가 체결"을 가정한다. 국내 증권사에서 종가 주문(MOC)이 안 되면 장 마감 직전 주문으로 근사해야 한다. 마감 직전은 겨울시간 기준 05:50 KST 전후로, 주인님 생활 시간대와 충돌할 수 있다.
- 크립토는 주말에도 움직이지만 ETF는 월요일 시가에야 반영된다. 손절(-25%)·대피(-10%)·약세 판정 규칙은 주말에 작동하지 않는다. 월요일 갭은 그대로 맞는다.
- SOLT 거래대금이 하루 $20M 안팎이라 개인 규모에는 충분하다. 다만 호가 스프레드는 BITU보다 넓다. 거래비용을 0.5%로 올려도 E는 +467%로 큰 차이가 없다.

## 8. 종합 판정과 다음 단계

| 질문 | 답 |
|---|---|
| 구현 가능한가 | 예. 하루 1회(09:00 KST 이후) 점검으로 기계적으로 실행할 수 있다. 단 문서·코드 불일치 8곳을 먼저 정리해야 "무엇을 따를지"가 정해진다. SOLT의 국내 취급 여부와 단일종목 예탁금 규정 적용 여부는 확인이 필요하다. |
| 현실성이 있는가 | 전략서 수치(+2,202%)는 과대하다. 현실 조건 기준값은 +499% / -62%(세후 약 +372%)다. 이것도 한 번의 상승에 기대는 표본 내 결과이고, 위험 대비로는 현물 보유와 같은 수준이다. |
| 표본 외에서 우위가 있었나 | 2015~2020 비트코인 뼈대 시험에서는 위험 대비로 현물 보유와 비슷했다. 우위는 확인되지 않았다. |

다음 단계(제안):
1. **문서·코드 통일.** 특히 다음 세 가지를 결정해야 한다.
   - 대피 중에도 200일선 규칙을 적용할지 (적용하면 낙폭 -77%→-71%)
   - 최종 매도 뒤 -35% 재성립을 요구할지
   - 분할익절 현금을 재투입할지
2. **엔진 기본값 변경.** "미국 거래일 체결 + 실측 레버리지 비용(BITU 16%, SOLT 20%)"으로 바꾸고, 앞으로 모든 비교를 이 기준으로 한다.
3. **규칙 수 축소와 표본 외 재확인.** 15개 규칙을 핵심 몇 개로 줄인 뒤 2015~2020 비트코인 구간에서 다시 확인한다. 이 구간을 튜닝에 쓰지 않은 상태로 유지한다.
4. **전방 검증.** 다음 사이클 신호를 날짜와 함께 미리 기록하고 사후에 판정한다. 그전까지 실자금은 전체의 일부로 제한한다.
5. **대안 비교.** 같은 신호를 코인 현물 1배(24시간 체결)로 운용하는 안(한 사이클 +630% / -36%)을 함께 비교한다. ETF 2배안보다 비용·주말 갭·국내 레버리지 규제 부담이 작다. 단 2027년부터 가상자산 과세가 적용될 예정이다.

def instrument(name, cal, drag=None, real=True, lev=2.0):
    """의사결정 달력(cal) 위의 상품 가격.
    상장 전: 현물 수익(직전 체결일 대비)×lev − 연비용(drag) 일할. 상장 후(real=True): 실제 조정종가 수익."""
    spot = SPOT[name].reindex(cal)
    per_year = 365.0 if len(cal) > 0 and (cal[1] - cal[0]).days == 1 and len(cal) == len(pd.date_range(cal[0], cal[-1])) else 252.0
    d = FEE[name] if drag is None else drag
    syn = np.clip(lev * spot.pct_change(), -0.999, None) - d / per_year
    r = syn.copy()
    if real:
        rr = REAL[name].reindex(cal)
        if per_year == 365.0:  # 원 엔진과 같은 방식: 비거래일은 직전 값 유지(=주말에 금요일 가격으로 체결 가능)
            rr = rr.ffill()
        rret = rr.pct_change()
        live = cal > REAL[name].index[0]
        r[live] = rret[live].fillna(0.0)
    r = r.fillna(0.0)
    return (1 + r).cumprod()


def spot_instrument(name, cal, lev=1.0, drag=0.0):
    spot = SPOT[name].reindex(cal)
    per_year = 365.0 if len(cal) == len(pd.date_range(cal[0], cal[-1])) else 252.0
    r = (lev * spot.pct_change() - drag / per_year).fillna(0.0)
    return (1 + r).cumprod()


DEF = dict(start="2020-04-11", end=None, cal="crypto7", drag_solt=None, drag_bitu=None, real=True, cost=0.003,

def code_flags(code_compat):
    """원 엔진 동작(True) vs 전략서 문구(False)로 갈리는 지점 6곳."""
    return dict(
        bear_after_final=not code_compat,   # 문서 §7: 최종매도 후 -35%가 다시 성립해야 대기 해제. 코드: 즉시 해제(약세장 저점=매도일 가격)
        reset_always=False,                 # 문서 §4·코드: 초기화는 3차 전까지만(§3-4·§9 서술과는 모순) → 둘 다 3차 전으로 둠
        bear200_in_evac=not code_compat,    # 문서 §5-5: 항상 적용. 코드: 눌림 대피(BITU) 중에는 200일선 규칙 건너뜀
        tp_vault=not code_compat,           # 문서 §5-6: 분할익절 현금은 그 사이클 재투입 금지. 코드: 다음 현금 매수 때 전부 재투입
        stop_ret_ladder=not code_compat,    # 문서 §5-4: 손절 후 복귀는 사다리 조건. 코드: 비율모멘텀>0이면 복귀
        buy_cap40=not code_compat,          # 문서 §4: 눈금 40(저점×2.7) 이상 신규 진입 금지. 코드: 없음
    )


def prep(P):
    cal_all = CAL if P["cal"] == "crypto7" else US_DAYS
    start = pd.Timestamp(P["start"]); end = pd.Timestamp(P["end"]) if P["end"] else CAL[-1]
    cal = cal_all[(cal_all >= start) & (cal_all <= end)]
    if P["spot_mode"]:
        px = {"SOLT": spot_instrument("SOLT", cal, P["lev"], P.get("drag_solt") or 0.0),
              "BITU": spot_instrument("BITU", cal, P["lev"], P.get("drag_bitu") or 0.0)}
    else:
        px = {"SOLT": instrument("SOLT", cal, P["drag_solt"], P["real"], P["lev"]),
              "BITU": instrument("BITU", cal, P["drag_bitu"], P["real"], P["lev"])}
    # 크립토 달력 신호
    ma_b = BTC.rolling(P["ma_bottom"]).mean(); ma200 = BTC.rolling(200).mean()
    below = (BTC < ma_b).astype(int)
    run_below = below.groupby((below == 0).cumsum()).cumsum()           # 연속 하회 일수
    rec100 = (BTC > ma_b) & (run_below.shift(1) >= P["below_days"])     # 60일 이상 하회 뒤 회복(사건)
    a200 = (BTC > ma200).astype(int); b200 = (BTC < ma200).astype(int)
    run_a200 = a200.groupby((a200 == 0).cumsum()).cumsum(); run_b200 = b200.groupby((b200 == 0).cumsum()).cumsum()
    g7 = BTC / BTC.shift(7) - 1
    ratio = SOL / BTC; rmom = ratio / ratio.shift(P["rot_n"]) - 1
    S = pd.DataFrame(dict(btc=BTC, sol=SOL, rec100=rec100, ab5=run_a200 >= 5, bb5=run_b200 >= 5,
                          above200=BTC > ma200, below200=BTC < ma200, surge=g7 >= P["surge"], rmom=rmom))
    return cal, px, S


def run(P_in):
    P = dict(DEF); P.update(P_in); F = code_flags(P["code_compat"]); F.update(P.get("flags", {}))
    cal, px, S = prep(P)
    A, B = P["instr"]
    cost = P["cost"]
    hold = {A: 0.0, B: 0.0}; cash = 1.0; vault = 0.0  # vault = 분할익절로 묶어 둔 현금(문서 규칙일 때만)
    st = dict(phase="WAIT", cyc_hi=BTC[:cal[0]].iloc[:-1].max(), bear_lo=None, tranche=0, bottom_ref=None,
              peak=None, evac=False, evac_lo=None, ladder=None, ent_sol=None, wait=None, cyc_eq=None, tp_done=0)
    log = []; eq = []
    last_info = cal[0] - pd.Timedelta(days=P.get("lag", 1))

    def V(t): return cash + vault + sum(hold[k] * px[k][t] for k in hold)

    def lev_val(t): return sum(hold[k] * px[k][t] for k in hold)

    def to(t, tgt, why):
        nonlocal cash, hold
        v = lev_val(t)
        if v <= 0: return
        v *= (1 - cost)  # 매도
        hold = {A: 0.0, B: 0.0}
        if tgt == "CASH": cash += v
        else: hold[tgt] = v * (1 - cost) / px[tgt][t]
        log.append((t.date(), "→" + tgt, why, round(V(t), 3)))

    def buy(t, frac, why, tgt):
        nonlocal cash
        amt = cash * frac
        if amt <= 0: return
        cash -= amt; hold[tgt] += amt * (1 - cost) / px[tgt][t]
        log.append((t.date(), "매수" + tgt, why, round(V(t), 3)))

    for t in cal:
        # 정보 구간: (직전 판단일의 정보 끝, 오늘 0시 UTC 종가] = 어제(달력)까지의 종가들
        info_end = t - pd.Timedelta(days=P.get("lag", 1))
        seg = S.loc[last_info + pd.Timedelta(days=1): info_end]
        last_info = info_end
        if len(seg) == 0:
            eq.append(V(t)); continue
        last = seg.iloc[-1]; b = last.btc; s = last.sol
        s_t = SOL.get(t, s)  # 체결일 SOL 종가(매수가 기준)
        bmax, bmin = seg.btc.max(), seg.btc.min()
        smax, smin = seg.sol.max(), seg.sol.min()
        rm = last.rmom; tool = A if (rm > P["rot_in"]) and not P["no_sol_rules"] else B
        hal = max([h for h in HALVINGS if h <= info_end], default=None)
        in_top = hal is not None and P["top_win"][0] <= (info_end - hal).days <= P["top_win"][1]
        st["cyc_hi"] = max(st["cyc_hi"], bmax)

        if st["phase"] == "WAIT":
            # 약세장 성립·저점 갱신(구간 내 일별 순회)
            for _, r in seg.iterrows():
                st["cyc_hi"] = max(st["cyc_hi"], r.btc)
                if r.btc <= st["cyc_hi"] * (1 - P["dd_bear"]):
                    st["bear_lo"] = r.btc if st["bear_lo"] is None else min(st["bear_lo"], r.btc)
                elif st["bear_lo"] is not None and not P["code_compat"]:
                    st["bear_lo"] = min(st["bear_lo"], r.btc)
            if st["bear_lo"] is not None and seg.rec100.any() and np.isfinite(px[tool][t]):
                st.update(phase="UP", tranche=1, bottom_ref=st["bear_lo"], peak=b, evac=False, ladder=None,
                          wait=None, cyc_eq=V(t), tp_done=0, run200=0)
                if F["tp_vault"]: cash += vault; vault = 0.0
                buy(t, 1 / 3, "1차 저점확인", tool); st["ent_sol"] = s_t
            eq.append(V(t)); continue

        # ---------- UP ----------
        # 초기화(3차 전, 또는 reset_always)
        if (st["tranche"] < 3 or F["reset_always"]) and bmin < st["bottom_ref"]:
            to(t, "CASH", "초기화(약세장 저점 이탈)")
            st.update(phase="WAIT", bear_lo=bmin, cyc_hi=bmin if P["code_compat"] else st["cyc_hi"], tranche=0)
            eq.append(V(t)); continue
        # 분할 진입 2·3차
        if st["tranche"] < 3 and cash > 0 and not (F["buy_cap40"] and b > st["bottom_ref"] * 2.7):
            if st["tranche"] == 1 and seg.ab5.any():
                buy(t, 1 / 2, "2차 200일선 5일", tool); st["tranche"] = 2; st["ent_sol"] = s_t
            elif seg.surge.any():
                buy(t, 1.0, "3차 7일 급등", tool); st["tranche"] = 3; st["ent_sol"] = s_t
        st["peak"] = max(st["peak"], bmax)
        # 분할익절
        if st["tp_done"] < len(P["tp_levels"]) and V(t) >= st["cyc_eq"] * P["tp_levels"][st["tp_done"]]:
            lv = lev_val(t)
            if lv > 0:
                for k in hold:
                    sell = hold[k] / 3; hold[k] -= sell; got = sell * px[k][t] * (1 - cost)
                    if F["tp_vault"]: vault += got
                    else: cash += got
                st["tp_done"] += 1; log.append((t.date(), "분할익절 1/3", f"{P['tp_levels'][st['tp_done']-1]}배", round(V(t), 3)))
        # 최종매도(고점창) / 눌림 대피(창 밖)
        if bmin <= st["peak"] * (1 - P["final_dd"]) and in_top:
            to(t, "CASH", "최종매도(고점창 -10%)")
            st.update(phase="WAIT", cyc_hi=st["peak"], bear_lo=None if F["bear_after_final"] else bmin, tranche=0)
            eq.append(V(t)); continue
        if (not in_top) and (not st["evac"]) and hold[A] > 0 and bmin <= st["peak"] * (1 - P["evac"]) and not P["no_sol_rules"]:
            to(t, B, "눌림 대피 BTC-10%"); st["evac"] = True; st["evac_lo"] = bmin; st["ladder"] = None; st["wait"] = None
        if st["evac"]:
            st["evac_lo"] = min(st["evac_lo"], bmin)
            if bmax >= st["evac_lo"] * (1 + P["re_up"]):
                st.update(evac=False, peak=b, ladder=None, wait=None, ent_sol=s_t)
                if hold[B] > 0 and tool == A: to(t, A, "+20% 반등 복귀")
                elif lev_val(t) == 0 and cash > 0: buy(t, 1.0, "+20% 반등 복귀", tool)
            if not F["bear200_in_evac"]:
                eq.append(V(t)); continue
        # 약세 판정(200일선 5일 하회) / 재진입
        # 200일선 하회 일수는 '사이클 진입 이후'부터 센다(진입 시점엔 대개 이미 200일선 아래라 달력 기준이면 즉시 매도되는 모순)
        hit5 = False
        for _, r in seg.iterrows():
            st["run200"] = st["run200"] + 1 if r.below200 else 0
            if st["run200"] >= 5: hit5 = True
        if hit5 and lev_val(t) > 0:
            to(t, "CASH", "200일선 5일 하회"); st.update(ladder=None, evac=False, wait="BEAR")
        if lev_val(t) == 0 and cash > 0 and st["wait"] in (None, "BEAR") and st["ladder"] is None and not st["evac"] \
                and last.above200 and st["run200"] == 0:
            if st["wait"] == "BEAR" or (P["code_compat"] and st["wait"] is None):
                buy(t, 1.0, "200일선 위 재진입", tool); st["wait"] = None; st["ent_sol"] = s_t
        # SOLT 관리: 손절 > 로테이션 이탈 > 사다리 익절
        if hold[A] > 0 and not P["no_sol_rules"] and not st["evac"]:
            if smin <= st["ent_sol"] * (1 - P["stop"]):
                to(t, "CASH", "손절 SOL-25%"); st["wait"] = "STOP"
                st["ladder"] = dict(xp=s_t, lo=s_t, t=t) if F["stop_ret_ladder"] else None
            elif rm < P["rot_out"]:
                to(t, B, "로테이션 이탈"); st["ladder"] = None
            elif smax >= st["ent_sol"] * P["x_ladder"]:
                to(t, "CASH", "1.5배 익절"); st["ladder"] = dict(xp=s_t, lo=s_t, t=t); st["wait"] = "LADDER"
        elif hold[A] == 0 and not P["no_sol_rules"] and not st["evac"] and (hold[B] > 0 or st["wait"] in ("LADDER", "STOP")):
            ok = False
            if st["ladder"] is not None:
                L = st["ladder"]; L["lo"] = min(L["lo"], smin)
                if L["lo"] <= L["xp"] * (1 - P["dip"]) or smax >= L["xp"] * (1 + P["brk"]) or (t - L["t"]).days >= P["tmax"]:
                    ok, why = True, "사다리 복귀"
            elif rm > P["rot_in"]:
                ok, why = True, "로테이션 복귀"
            if ok:
                if hold[B] > 0:
                    if tool == A: to(t, A, why)
                elif cash > 0: buy(t, 1.0, why, tool)
                st.update(ladder=None, wait=None, ent_sol=s_t)
        eq.append(V(t))
    E = pd.Series(eq, index=cal)
    return E, log


def stats(E, a=None, b=None):
    e = E[a:b] if (a or b) else E
    tot = e.iloc[-1] / e.iloc[0]; yrs = (e.index[-1] - e.index[0]).days / 365.25
    return dict(ret=tot - 1, cagr=tot ** (1 / yrs) - 1 if yrs > 0 else np.nan, mdd=(e / e.cummax() - 1).min())


def bench(name, cal, drag=None, real=True, lev=2.0):
    if name in ("SOL", "BTC"):
        s = (SOL if name == "SOL" else BTC).reindex(cal)
        return s / s.dropna().iloc[0]
    return instrument(name, cal, drag, real, lev)

def _fmt(e, a=None, b=None):
    e = (e[a:b] if (a or b) else e).dropna(); tot = e.iloc[-1] / e.iloc[0]; yrs = (e.index[-1] - e.index[0]).days / 365.25
    dd = (e / e.cummax() - 1).min(); cg = tot ** (1 / yrs) - 1
    return f"{tot-1:+,.0%} / MDD {dd:.0%} / 연 {cg:+.0%} / 연÷MDD {cg/abs(dd):.2f}"


def _aftertax(e, a, rate=.22):
    e = e[a:].dropna(); v = 1.0; prev = e.iloc[0]
    for y in sorted(set(e.index.year)):
        ey = e[e.index.year == y]; r = ey.iloc[-1] / prev - 1; v *= 1 + (r * (1 - rate) if r > 0 else r); prev = ey.iloc[-1]
    return v - 1
