## 2. 발견한 오류

등급: **A** 수치·사실 오류, **B** 코드 버그 또는 문서·코드 불일치, **C** 설계 결함(규칙은 맞게 돌지만 비효율), **D** 현실성 전제.

### A1. 달력 결손 — "10-31 기준" 수치가 10-26 기준 (영향 큼)
- 브랜치의 `data/prices/SPY.csv`가 2026-10-26에서 끝난다(main은 10-30까지). 엔진은 이 달력으로만 체결하므로 10-27·28·29·30 네 거래일이 통째로 빠졌다.
- 그 사이 BITU 조정종가 -8.4%(10-26 → 10-30). 보유분 100% BITU라 평가액 38.49 → **35.25**.
- 정정값(10-30 기준): 한 사이클 **+499% / -62% / 연 57% / 연÷낙폭 0.93**, 전체 +3,425%, 실제 ETF 구간 +12%, 세후 +371%. 사이클 진입(cyc_eq 31.82) 대비 **1.11배**(문서 §9 "약 1.3배"는 10-26 기준으로도 1.21배라 틀림).
- `forward_log.csv` 첫 행(2026-10-31, equity 38.4906)도 같은 이유로 틀림. 전방 검증 기준 평가액 1.000의 실제 날짜는 10-26 체결가다.
- 운영 문제: main에는 `data/crypto/`가 없고, 브랜치에는 SPY 갱신이 없다. `cycle_signal_daily.py`는 두 자료가 같은 브랜치에 있어야 하므로 **현재 어느 브랜치에서도 올바른 일일 신호를 내지 못한다**. 또 `cycle_signal_daily.py`는 날짜를 BTC 마지막 날(10-31)로 찍지만 상태는 마지막 미국 거래일 체결 기준이라 날짜 표기 자체가 어긋난다.

### A6. 레버리지 비용 실측치의 불확실성
- 재측정: BITU 대 2×IBIT 648거래일 **연 -14.5%**(문서 -16.0%). SOLT 대 2×SOL은 크립토 종가를 어느 날에 맞추느냐에 따라 **연 -15.9% ~ -23.9%**(문서 -20.2%). ETF 종가(16:00 EST)와 크립토 UTC 종가가 8시간 어긋나 정확한 정렬이 없다.
- 문서값은 범위 안에 있어 오류는 아니지만, ±4%p 불확실성을 명시해야 한다. 2023-10~2024-03 수익의 대부분이 합성 SOLT 구간이라 이 가정이 성적에 직접 들어간다(v2.1에서 30~40%로 올려도 결론은 유지됨을 확인).

### B1. 2028-01-01 최종매도 활성화 코드 버그 (코드 ≠ 문서)
```python
# cycle_engine_v2.py 87행 (현재)
in_top = (...300~600일...) or (info_end >= TOP_FORCE_FROM and hal is not None and (info_end - hal).days <= P["top_win"][1] + 365)
```
- 2028-01-01에 `hal`은 2024-04-20이고 경과 1,351일 > 965일이라 **거짓**. 2028-04-15 반감기가 지나야 참이 된다. 즉 문서가 약속한 "2028-01-01 활성화"는 2028-01-01~04-14 석 달 반 동안 꺼져 있다.
- 또 2028-04-15부터는 2030-12까지 쭉 참이어서, 그 안에 새 사이클 진입이 생기면 첫 -10%에 즉시 최종매도된다.
- 수정안: `in_top = in_win or (TOP_FORCE_FROM <= info_end <= pd.Timestamp("2029-12-06"))` — 2028-01-01부터 다음 반감기 +600일까지만 강제.

### B2. 약세장 저점(bear_lo) 갱신 버그 → 2021년 초기화·진입상한 무력화
- WAIT 구간에서 `bear_lo`는 한 번 설정되면 신고가가 나와도 지워지지 않고 최솟값만 추적한다(90~92행). v2.1 검증에서 2017~18년에 지적한 것과 같은 결함이 v2 엔진에 남아 있다.
- 결과: 2020-04 시작 시 2017년 고점 대비 -35%가 성립해 `bear_lo ≈ 6,642`가 되고, 2020-12 신고가·2021-04 64k·2021-05 -54% 하락을 거쳐 **2021-08-02 진입 때 bottom_ref = 6,642**(문서 §3 정의대로면 29,807)가 됐다.
  - 초기화 기준이 6,642라 사실상 없음. 진입상한(×2.7 = 17,934)에 모든 가격이 걸려 **2·3차 진입이 차단**됨(2021년은 200일선 재진입 규칙이 우연히 전량 매수를 대신했다).
- 영향: 사이클2(2022-11-21~) **없음**. 전체 구간은 +3,749% → 문서 규칙대로(B2+B3+B4 수정) **+2,957%**(2021 +469% → +352%). 표본 외 2015~20 뼈대는 +1,862% → +1,817%.
- 문서 §3도 보완 필요: "약세 성립 당시 고점을 종가로 넘으면 약세 판정을 해제하고, 다음 -35%는 새 고점 기준으로 다시 센다"를 명시.

### B3. 약세 대기(200일선 매도 후) 중 2·3차 진입 허용
- 102~104행은 `wait == "BEAR"`를 보지 않는다. 200일선 5일 하회로 전량 현금이 된 상태에서 7일 +15% 급등이 나오면 3차가 **현금 전부를 매수**하고, 같은 날 뒤쪽 200일선 검사에서 다시 매도한다.
- 실제 발생: 표본 외 2018-07-18 "매수 3차 → 같은 날 →CASH 200일선"(왕복 비용만 지불). 2026-04-22~06-30 대기 중에도 조건만 맞았으면 똑같이 터졌다.
- 수정안: 2·3차 조건에 `and st["wait"] != "BEAR"` 추가. 문서 우선순위(2·3차 > 약세 판정)에도 "약세 대기 중에는 2·3차를 넣지 않는다"를 명시.

### B4. 사다리·손절 대기 중 200일선 하회 미기록
- 122행은 보유분이 있을 때만 `wait="BEAR"`로 바꾼다. 사다리 익절로 현금인 상태에서 200일선이 깨지면 약세가 기록되지 않고, 60일 뒤 사다리 복귀가 하락장에서 전량 매수한 뒤 다음 거래일에 200일선 규칙으로 되판다. 역사적 발동 0회지만 규칙상 구멍.
- 수정안: `hit5`이고 보유 0, `wait in ("LADDER","STOP")`이면 `wait="BEAR"`, 사다리 해제.

### B5. 최종매도 기준 "고점"의 정의 불일치
- 코드는 눌림 대피 복귀 때 `peak`를 현재가로 초기화하고(116행), 이 `peak`를 눌림 대피와 최종매도 둘 다에 쓴다. 문서 §0·§6은 "사이클 고점 × 0.9"라고 쓴다.
- 대피 복귀 때 초기화하지 않으면(문서 문구대로) 복귀 직후 즉시 재대피가 반복되므로 **코드 동작이 합리적**이다. 문서 쪽을 "고점 = 사이클 진입 후 고점이며, 눌림 대피 복귀 때 복귀일 종가로 다시 시작한다"로 고칠 것. 수치 영향은 -7%p(+554% → +547%).

### B6. 초기화가 로그에 남지 않음
- `to()`는 보유 0이면 바로 반환해 로그를 남기지 않는다. 2022-06, 2022-11, 2026-06 세 번의 초기화(이미 현금 상태)가 기록에 없어, 2022-09-13과 2026-08-20 "1차 저점확인"이 어떻게 가능했는지 로그만으로는 추적이 안 된다. 초기화는 보유 유무와 무관하게 로그에 남겨야 한다.

### C1. 재진입 → 익일 대피, 같은 날 이중 체결 (비효율)
- 200일선 재진입은 SOLT로 들어가고, 다음 거래일 BTC가 이미 사이클 고점 -10% 아래라 즉시 BITU로 대피한다. 2024-07-15/18, 08-26/27, 09-25/26에 반복(각 왕복 0.6%+0.6%). 2023-08-22는 대피(→BITU)와 200일선(→현금)이 같은 날 발동해 비용만 두 번.
- 정리안(재진입 때 이미 -10% 아래면 BITU로 직접 진입, 같은 날 200일선 성립 시 대피 생략)을 시험했으나 성적은 ±1%p로 **수익 개선이 아니다**(SOLT 하루 노출이 우연히 득이었던 날이 있음). 논리 정리 차원에서만 선택.

### C2. 저점 확인 60일 기준의 칼날 (문서가 이미 인정)

### D2. BITU 분배금과 국내 세금 (백테스트 밖)

- 백테스트는 조정종가로 분배금이 무세 재투자된다고 본다. 국내 투자자는 분배금에 배당소득세 15.4%가 붙고(연 2,000만원 초과 시 금융소득종합과세), 분배로 떨어진 가격은 양도차익을 줄이지만 손실은 이월되지 않는다. 2025-12-24 같은 분배일에 BITU를 들고 있었다면 NAV의 약 4%가 세금으로 빠진다. 2022~26 백테스트는 그날 현금이어서 영향이 없었지만, **12월 BITU 보유는 분배 일정을 확인하고 결정**해야 한다(ProShares는 12월 말 대규모 분배 전력).

### D3. §11 규제 문구
- 사전교육·기본예탁금 조항은 주인님께 적용되지 않는 것으로 확인된 바 있어 삭제 가능. SOLT 국내 취급 여부만 증권사 앱에서 확인.

### D4. 신호 시차와 주말
- 체결(겨울 06:00 KST, 여름 05:00 KST)에 쓰는 신호는 전날 09:00 KST 크립토 종가로, 21시간 전 값이다. 체결 시점의 실시간 가격은 규칙에 쓰지 않는다. 주말 급변은 월요일 종가에 처음 반응한다. 문서가 이미 밝힌 대로이며 오류는 아니지만, 2026-10-29~30처럼 BTC -4%·BITU -10%가 나오는 날엔 하루 시차가 그대로 손익이 된다.

### D5. 세후 근사
- 연간 평가액 변화(미실현 포함)에 22%를 매긴다. 실제 과세는 실현 차익 기준, 연 250만원 공제, 손실 이월 없음이다. 보유 중 미실현분이 큰 해(2023~24)에는 세금을 과대 계산하고, 분배금 세금(D2)은 빠져 있다. 근사라고 밝혀져 있으나 "세후 +406%"는 두 방향 오차를 모두 가진 값이다.

def ld(n, c="close"):

def instrument(name, cal, lev=2.0, drag=None, use_real=True):
    spot = SPOT[name].reindex(cal); d = DRAG[name] if drag is None else drag
    days = pd.Series(cal, index=cal).diff().dt.days.fillna(0)
    r = np.clip(lev * spot.pct_change(), -0.999, None) - d * days / 365.0
    if use_real and lev == 2.0:
        rr = REAL[name].reindex(cal).pct_change(); live = cal > REAL[name].index[0]
        r = r.where(~live, rr.fillna(0.0))
    return (1 + r.fillna(0.0)).cumprod()

P0 = dict(start="2020-04-11", end=None, mode="etf", lev=2.0, cost=0.003, drag=None, use_real=True, core=False,

def signals(P):
    ma_b = BTC.rolling(P["ma_bottom"]).mean(); ma200 = BTC.rolling(200).mean()
    bl = (BTC < ma_b).astype(int); run_bl = bl.groupby((bl == 0).cumsum()).cumsum()
    rec = (BTC > ma_b) & (run_bl.shift(1) >= P["below_days"])
    a2 = (BTC > ma200).astype(int); run_a2 = a2.groupby((a2 == 0).cumsum()).cumsum()
    g7 = BTC / BTC.shift(7) - 1; ratio = SOL / BTC; rmom = ratio / ratio.shift(P["rot_n"]) - 1
    return pd.DataFrame(dict(btc=BTC, sol=SOL, rec=rec, ab5=run_a2 >= 5, above200=BTC > ma200, below200=BTC < ma200,
                             surge=g7 >= P["surge"], rmom=rmom, ma200=ma200))

def run(P_in, cal_override=None):
    P = dict(P0); P.update(P_in)
    cal = CAL7 if P["mode"] == "spot" else (US if cal_override is None else cal_override)
    start = pd.Timestamp(P["start"]); end = pd.Timestamp(P["end"]) if P["end"] else CAL7[-1]

    lev = 1.0 if P["mode"] == "spot" else P["lev"]
    px = {k: instrument(k, cal, lev, 0.0 if P["mode"] == "spot" else P["drag"], P["use_real"] and P["mode"] != "spot") for k in ("SOLT", "BITU")}
    S = signals(P); A, B = "SOLT", "BITU"; cost = P["cost"]; core = P["core"]

    st = dict(phase="WAIT", cyc_hi=BTC[:cal[0]].iloc[:-1].max(), bear_lo=None, bear_hi=None, tranche=0, bottom_ref=None, peak=None,
              evac=False, evac_lo=None, ladder=None, ent_sol=None, wait=None, cyc_eq=None, tp_done=0, run200=0)
    log = []; eq = []; last_info = cal[0] - pd.Timedelta(days=1)

    LV = lambda t: sum(hold[k] * px[k][t] for k in hold)
    def to(t, tgt, why):
        nonlocal cash, hold
        v = LV(t)
        if v <= 0: return
        v *= 1 - cost; hold = {A: 0.0, B: 0.0}
        if tgt == "CASH": cash += v
        else: hold[tgt] = v * (1 - cost) / px[tgt][t]
        log.append((t.date(), "→" + tgt, why, round(V(t), 4), round(BTC[t]), round(SOL[t], 1)))
    def buy(t, frac, why, tgt):
        nonlocal cash
        amt = cash * frac
        if amt <= 0: return
        cash -= amt; hold[tgt] += amt * (1 - cost) / px[tgt][t]
        log.append((t.date(), "매수" + tgt, why, round(V(t), 4), round(BTC[t]), round(SOL[t], 1)))
    for t in cal:
        info_end = t - pd.Timedelta(days=1); seg = S.loc[last_info + pd.Timedelta(days=1): info_end]; last_info = info_end
        if len(seg) == 0: eq.append(V(t)); continue
        last = seg.iloc[-1]; b, s = last.btc, last.sol; s_t = SOL[t]
        bmax, bmin, smax, smin = seg.btc.max(), seg.btc.min(), seg.sol.max(), seg.sol.min()
        rm = last.rmom; tool = B if core else (A if rm > P["rot_in"] else B)
        hal = max([h for h in HALV if h <= info_end], default=None)
        in_win = hal is not None and P["top_win"][0] <= (info_end - hal).days <= P["top_win"][1]
        if P["top_force_fix"]:
            in_top = in_win or info_end >= P["top_force"]
        else:
            in_top = in_win or (info_end >= P["top_force"] and hal is not None and (info_end - hal).days <= P["top_win"][1] + 365)
        if st["phase"] == "WAIT":
            for _, r in seg.iterrows():
                st["cyc_hi"] = max(st["cyc_hi"], r.btc)
                if P["bear_reset_newhigh"] and st["bear_lo"] is not None and r.btc > st["bear_hi"]:
                    st["bear_lo"] = None; st["bear_hi"] = None
                if r.btc <= st["cyc_hi"] * (1 - P["dd_bear"]):
                    if st["bear_lo"] is None: st["bear_hi"] = st["cyc_hi"]
                    st["bear_lo"] = r.btc if st["bear_lo"] is None else min(st["bear_lo"], r.btc)
                elif st["bear_lo"] is not None: st["bear_lo"] = min(st["bear_lo"], r.btc)
            if st["bear_lo"] is not None and seg.rec.any() and np.isfinite(px[tool][t]):
                st.update(phase="UP", tranche=1, bottom_ref=st["bear_lo"], peak=b, evac=False, ladder=None, wait=None, tp_done=0, run200=0)

        st["cyc_hi"] = max(st["cyc_hi"], bmax)
        if st["tranche"] < 3 and bmin < st["bottom_ref"]:

            for k in hold: sell = hold[k] / 3; hold[k] -= sell; vault += sell * px[k][t] * (1 - cost)

        if bmin <= st["peak"] * (1 - P["final_dd"]) and in_top:

        pre_hit5 = False
        if P["skip_evac_if_hit5"]:
            r200 = st["run200"]

                r200 = r200 + 1 if r.below200 else 0
                if r200 >= 5: pre_hit5 = True
        if not core and not in_top and not st["evac"] and hold[A] > 0 and bmin <= st["peak"] * (1 - P["evac"]) and not pre_hit5:
            to(t, B, "눌림 대피 BTC-10%"); st.update(evac=True, evac_lo=bmin, ladder=None, wait=None)
        if st["evac"]:

                st.update(evac=False, ladder=None, wait=None, ent_sol=s_t)
                if P["peak_reset_evac"]: st["peak"] = b
                if hold[B] > 0 and tool == A: to(t, A, "+20% 반등 복귀")
        hit5 = False
        for _, r in seg.iterrows():
            st["run200"] = st["run200"] + 1 if r.below200 else 0
            if st["run200"] >= 5: hit5 = True
        if hit5 and P["use200"] and LV(t) > 0: to(t, "CASH", "200일선 5일 하회"); st.update(ladder=None, evac=False, wait="BEAR")
        elif hit5 and P["ladder_block_in_bear"] and LV(t) == 0 and st["wait"] in ("LADDER", "STOP"): st.update(ladder=None, wait="BEAR")
        if LV(t) == 0 and cash > 0 and st["wait"] == "BEAR" and last.above200 and st["run200"] == 0:
            if P["reentry_direct_evac"] and not core and not in_top and b <= st["peak"] * (1 - P["evac"]):
                buy(t, 1.0, "200일선 위 재진입(대피 상태, BITU)", B); st.update(wait=None, ent_sol=s_t, evac=True, evac_lo=bmin)
            else:
                buy(t, 1.0, "200일선 위 재진입", tool); st.update(wait=None, ent_sol=s_t)
        if core: eq.append(V(t)); continue
        if hold[A] > 0 and not st["evac"]:
            if smin <= st["ent_sol"] * (1 - P["stop"]): to(t, "CASH", "손절 SOL-25%"); st.update(wait="STOP", ladder=dict(xp=s_t, lo=s_t, t=t))
            elif rm < P["rot_out"]: to(t, B, "로테이션 이탈"); st["ladder"] = None
            elif smax >= st["ent_sol"] * P["x_ladder"]: to(t, "CASH", "익절 사다리"); st.update(ladder=dict(xp=s_t, lo=s_t, t=t), wait="LADDER")
        elif hold[A] == 0 and not st["evac"] and (hold[B] > 0 or st["wait"] in ("LADDER", "STOP")):
            ok = False
            if st["ladder"] is not None:
                L = st["ladder"]; L["lo"] = min(L["lo"], smin)
                if L["lo"] <= L["xp"] * (1 - P["dip"]) or smax >= L["xp"] * (1 + P["brk"]) or (t - L["t"]).days >= P["tmax"]: ok, why = True, "사다리 복귀"
            elif rm > P["rot_in"]: ok, why = True, "로테이션 복귀"
            if ok:
                if hold[B] > 0:
                    if tool == A: to(t, A, why)
                elif cash > 0: buy(t, 1.0, why, tool)
                st.update(ladder=None, wait=None, ent_sol=s_t)
        eq.append(V(t))
    E = pd.Series(eq, index=cal); st["hold"] = dict(hold); st["cash"] = cash; st["vault"] = vault
    return E, log, st

def stats(e, a=None, b=None):
    e = (e[a:b] if (a or b) else e).dropna(); tot = e.iloc[-1] / e.iloc[0]; yrs = max((e.index[-1] - e.index[0]).days / 365.25, 1e-9)
    dd = (e / e.cummax() - 1).min(); cg = tot ** (1 / yrs) - 1
    return dict(ret=tot - 1, mdd=dd, cagr=cg, calmar=cg / abs(dd) if dd else 0)
def fmt(e, a=None, b=None):
    s = stats(e, a, b); return f"{s['ret']:+,.0%} / 낙폭 {s['mdd']:.0%} / 연 {s['cagr']:+.0%} / 연÷낙폭 {s['calmar']:.2f}"
def aftertax(e, a, rate=0.22):
    e = e[a:].dropna(); v = 1.0; prev = e.iloc[0]
    for y in sorted(set(e.index.year)):
        ey = e[e.index.year == y]; r = ey.iloc[-1] / prev - 1; v *= 1 + (r * (1 - rate) if r > 0 else r); prev = ey.iloc[-1]
    return v - 1
def yearly(e, ys=range(2021, 2027)):
    return {y: e[:f"{y}-12-31"].iloc[-1] / e[:f"{y-1}-12-31"].iloc[-1] - 1 for y in ys}
